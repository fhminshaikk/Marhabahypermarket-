# Marhaba Hypermarket Website

Interactive online catalogue and cart system for Marhaba Hypermarket (MA Square, Thengol, Othukkungal).
Customers browse products, check items into a shopping cart, choose **Home Delivery** or **Store Pickup**, enter their name and address, and press **Send Order to WhatsApp**.

No server or database is needed, so it is free to host on GitHub Pages.

## Files

- `index.html` page layout, product modal, and shopping cart drawer
- `style.css` design, smooth animations, and dark mode styling
- `app.js` shop settings, inventory, shopping cart logic, and WhatsApp integration
